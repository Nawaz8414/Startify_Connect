🚀 Startify Connect

🔗 Live Demo: https://startify-connect.vercel.app/

 Overview

Startify Connect is a full-stack web platform designed to connect students, entrepreneurs, and startup enthusiasts in a centralized environment. It enables users to share startup ideas, collaborate with others, communicate in real-time, and leverage AI assistance for building innovative projects.

The platform solves the problem of fragmented networking by bringing together idea sharing, collaboration, and communication into a single ecosystem.

✨ Features
🔐 Authentication
Secure login & signup system
Role-based access (Founder / Institute)

⚙️ Installation & Setup
1️⃣ Clone the Repository
git clone https://github.com/Nawaz8414/Startify_Connect.git
cd Startify_Connect
2️⃣ Backend Setup
cd startify-backend
npm install

Create .env file:

MONGO_URL=your_mongodb_url
JWT_SECRET=your_secret_key

Run backend:

npm run dev
3️⃣ Frontend Setup
cd startify-frontend
npm install
npm run dev
